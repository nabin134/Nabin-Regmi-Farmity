README FILE (Farmity)
Project Title
Farmity – Agricultural E-commerce and Advisory Platform

Project Description
Farmity is a web-based system designed to connect farmers, vendors, agricultural experts, and customers. It provides a complete platform for buying and selling crops and tools, consulting experts, and managing agricultural activities digitally.
Project Objective
The main objective of this project is to create a centralized platform that improves agricultural trade, provides expert guidance, and ensures secure and transparent transactions.

Features
•	User Registration & Login (including Google Sign-In) 
•	Farmer crop selling system 
•	Vendor tool selling system 
•	Customer shopping (cart & orders) 
•	Payment integration (eSewa & COD) 
•	Expert consultation (chat & appointment) 
•	Blog system for knowledge sharing 
•	KYC verification system 
•	Admin dashboard & commission system 
•	Email notifications & customer support
